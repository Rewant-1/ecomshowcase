# Ecom Showcase — Stellar Precision Demo

A responsive, animated product showcase website (non‑ecommerce) built with React + Tailwind CSS.

This repo started from a third‑party landing page template, then was customized as a “Stellar Precision” demo to practice UI, layouts, and routing.

## What’s inside

- Category listing + category detail pages (React Router)
- Dummy product catalog (names, prices, descriptions) driven by data
- Clean light theme, responsive layout, and hover/scroll animations

## Tech stack

- React 18
- Vite
- Tailwind CSS (+ PostCSS + Autoprefixer)
- React Router
- AOS (Animate On Scroll)

## Quick start

```bash
npm install
npm run dev
```

Build + preview:

```bash
npm run build
npm run preview
```

## Project structure

- `src/pages/` – route pages (`Home`, `CategoryList`, `CategoryPage`)
- `src/partials/` – landing page sections (hero, features, footer, etc.)
- `src/data/products.js` – demo catalog + categories
- `src/css/` – Tailwind entry + additional styles
